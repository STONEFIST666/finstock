# FinStock

FinStock is a modern stock market analysis platform that allows users to search stocks, view live market data, analyze company fundamentals, and eventually manage investments through interactive financial tools.

## Current Features

- Live Stock Quotes
- Company Overview
- Responsive UI
- Express + EJS Architecture
- Alpha Vantage Integration

## Tech Stack

- Node.js
- Express.js
- EJS
- Axios
- Alpha Vantage API

## Upcoming Features

- Historical Charts
- Watchlist
- News
- Portfolio Tracker
- Technical Indicators
